# Схема кнопок геймпада

[In English](../en/CONTROLS.md) / [На главную](../../README.ru.md)

Стандартная раскладка из `GamepadBindings.cpp` и `gamedata/scripts/`. Переназначить кнопки боя и меню можно в `Настройки -> Управление -> Геймпад`.

Обозначения жестов:
- Нажатие: короткое нажатие и отпускание (`< 300 мс`).
- Удержание: зажать кнопку на `250-300 мс` (около `1 с` с круговой шкалой на необратимых действиях).
- Сочетание (`A + B`): сначала зажать `LT` или `LB`, затем нажать вторую кнопку.

## Передвижение и бой

| Кнопка | Нажатие | Удержание | Сочетание |
|---|---|---|---|
| `LS` (левый стик) | Ходьба и бег на 360° (в спринте рулит в пределах 60°; ослабление наклона ниже 70% переводит обратно на шаг) | - | - |
| `L3` (нажатие `LS`) | Включить спринт | - | - |
| `RS` (правый стик) | Поворот камеры и прицел | - | - |
| `R3` (нажатие `RS`) | Опустить или поднять оружие | - | - |
| `LT` | Прицеливание | Удерживать прицел | `LT + LB` наклон влево, `LT + RB` наклон вправо |
| `RT` | Выстрел / бросок болта или гранаты | Очередь | - |
| `A` | Прыжок | - | - |
| `B` | Присесть | Низкий присед (`300 мс`) | `LB + B` свободный поворот головы |
| `X` | Действие / перезарядка / снять клин | Проверить магазин (`AmmoCheck`) | `LT + X` принудительная перезарядка |
| `Y` | Следующее оружие / убрать ствол | Веер оружия (выбор через `RS`) | `LB + Y` быстрая граната |
| `LB` | Быстрый слот / болт | Колесо быстрого доступа (`250 мс`) | Модификатор для `B`, `Y`, `View`, крестовины |
| `RB` | Быстрый удар прикладом или ножом | Достать нож или бинокль (`300 мс`) | - |
| `Крестовина Вверх` | Налобный фонарь | ПНВ (`300 мс`) | `LT + Вверх`: приблизить прицел / Free Zoom |
| `Крестовина Влево` | Детектор | Бросить болт (`300 мс`) | `LB + Крестовина`: закреплённые слоты |
| `Крестовина Вправо` | Режим огня | Подствольный гранатомёт (`300 мс`) | `LB + Крестовина`: закреплённые слоты |
| `Крестовина Вниз` | Сменить тип патронов | Колесо патронов (`300 мс`) | `LT + Вниз`: отдалить прицел |
| `Menu` (Start) | Меню паузы | - | - |
| `View` (Back) | Открыть или закрыть инвентарь | Полноэкранный 2D-КПК (`300 мс`) | `LB + View`: памятка по управлению |

Действия в колесе быстрого доступа (их также можно повесить на отдельную кнопку в настройках): 3D-КПК в руках (`Pda3DToggle`), протереть маску (`MaskClean`) и быстрая перезарядка со сбросом магазина (`FastReload`).

## Инвентарь, обыск, торговля и техник

| Кнопка | Инвентарь | Обыск / тайник | Торговля | Техник |
|---|---|---|---|---|
| `LS` / крестовина | Переход по ячейкам | Переход по ячейкам | Переход по ячейкам | Выбор вещей, деталей и ветвей апгрейда |
| `RS` (наклон / нажатие) | Прокрутка описаний; нажатие включает 100%-характеристики | То же | То же | Прокрутка; нажатие включает 100%-характеристики |
| `View` | Снаряжение / Рюкзак | По кругу: Контейнер, Снаряжение, Рюкзак | По кругу: Торговец, Снаряжение, Рюкзак | По кругу: Рюкзак, Снаряжение, Техник |
| `LT` / `RT` | Вкладки категорий | Вкладки категорий | Вкладки категорий | Вкладки категорий |
| `A` | Использовать / надеть (`Удерж. A`: вся пачка) | Взять (`Удерж. A`: вся пачка) | В корзину (`Удерж. A`: вся пачка) | Выбрать предмет или апгрейд |
| `Y` | Быстро переместить / надеть | Быстро переложить | В корзину / из корзины | Подробности апгрейда |
| `X` | Меню предмета (`Удерж. X`: разобрать) | То же | Меню предмета (`Удерж. X`: доп. действие) | Контекстное действие |
| `LB` | - | Нажатие: Взять всё; Удержание: Автосборщик | Купить корзину | - |
| `RB` | Фильтр медицины | Сложить всё | Продать корзину | - |
| `L3` | — | Переименовать личный тайник | Очистить непустые корзины | — |
| `B` / `Menu` | Закрыть подменю или инвентарь | То же | То же | Шаг назад / выход |

## 2D и 3D КПК

| Кнопка | Полноэкранный 2D-КПК (`Удерж. View`) | 3D-КПК в руках |
|---|---|---|
| `LT` / `RT` | Вкладки КПК (Задания, Отношения, Контакты, Статистика, Сообщения, Справочник, Радио) | - |
| `LS` / `L3` | Движение карты или курсора; `L3` центрирует на игроке | - |
| `LB` / `RB` | Масштаб карты `-` / `+` (или фильтры заданий) | - |
| `View` | Нажатие: список заданий; Удержание: легенда карты | - |
| `X` | Меню метки / `PAW` (`Удерж. X` на удалении стирает свою метку) | - |
| `Y` | Полоса фильтров значков карты | Курсор на экране 3D-КПК |
| `A` / `B` | Подтвердить / закрыть | `B` убирает 3D-КПК |

## Колесо быстрого доступа и веер оружия

Удержание `LB` (`250 мс`) открывает колесо `HarukaSai`: наклоните `RS` на нужный сектор и отпустите `LB` (либо нажмите `A`). `LT`/`RT` переключают вкладки колеса, крестовина при отпущенном `RS` вызывает закреплённый слот, а при наведённом `RS` закрепляет выбранный сектор; `B` закрывает колесо.

Удержание `Y` (`300 мс`) открывает веер выбора оружия: наведите `RS` на нужный ствол и отпустите `Y`.

## Верстак, убежище и остальные окна

| Окно | Управление |
|---|---|
| Верстак (`UIWorkshop`) | `LT`/`RT` переключают Состояние, Ремонт, Модификации и Создание; `LS`/крестовина + `A` выбирают вещь, деталь или рецепт; `LB`/`RB` меняют набор инструментов или фильтр; `View` открывает инструкции; `Удерж. X` (`1 с`) запускает ремонт, апгрейд или крафт; `Y` показывает описание; `B` возвращает назад. |
| Расстановка мебели | `LS` двигает по XZ, `RS` вращает и меняет высоту Y (`LB`/`RB` тоже вращают), зажатый `LT` замедляет шаг в 10 раз, `A` ставит предмет, `X` переключает коллизию, `Y` выравнивает по осям, `View` меняет режим, `B` отменяет. |
| Мебель в мире | Поставленный верстак: `X` открыть, `Y` тайник, `Удерж. B` (`1.8 с`) забрать. Лампа, радио, пианино: `A` питание или станция, `LB`/`RB` громкость, `Y` топливо или пуск/стоп, `Удерж. X` (`1 с`) забрать. Ноутбук торговли: `A` торговля, `X` обновить. |
| Полевые окна и сон | Разделка мутантов, полевая готовка, ремонт, плавильня, сон: `LS`/крестовина + `A` выбор, `Удерж. X` забрать/приготовить/лечь спать, `B` выход. Плитка: `X` готовить, `Y` тайник. |
| Диалоги и «21 очко» | Диалоги: крестовина/`LS` + `A` ответить, `X` торговля, `B` уйти. «21 очко»: `LS`/крестовина + `A` ставка и ход, `Удерж. X` зафиксировать ставку, `B` выйти. |
| Напарники, перки, `MCM` | Обмен с напарником и приказы отряду, `Experience` и `HarukaSkills` (`View` прыгает между ними, `Удерж. X` изучает перк), настройки ЛЦУ, `BHS`, цветокоррекция, кодовый замок, создание тайника, рецепты, карточки обучения `NPE` и все 14 типов настроек в `UI_MCM` (`View` меняет колонку). В незнакомом окне стороннего мода нажатие `R3` включает виртуальный курсор мыши. |

## Экранная клавиатура (`RU` / `EN`)

Открывается сама при выборе любого текстового поля (имя сейва, название тайника, метка `PAW`, имя персонажа, поиск в `MCM` и верстаке): `LS`/крестовина двигают рамку, `A` печатает символ или шаблон, `X` стирает (при зажатии повторяется), `Y` ставит пробел, `L3`/`LT` меняют регистр, `R3`/`LB`/`RB` переключают `RU ЙЦУКЕН` и `EN QWERTY`, `Menu` подтверждает ввод, `B` отменяет.

## Настройки и переназначение кнопок

Меню `Настройки -> Управление -> Геймпад` состоит из четырёх вкладок (удержание `X` на 1 секунду сбрасывает открытую вкладку):
- `В мире` и `Инвентарь и меню`: текущие привязки действий.
- `Прицеливание`: чувствительность по осям, множитель прицела, разгон поворота, кривая отклика (`Линейная`, `Степенная`, `S-кривая`), мёртвые зоны и помощь в прицеливании (`Выкл`, `Слабая`, `Средняя`, `Сильная` + отдельные ползунки замедления и доводки).
- `Другие настройки`: 5 ползунков вибрации, выбор значков `Dot Marks`, переключение приседа и спринта (удержание или нажатие), скорость и кнопка вызова курсора, `Назначить кнопки` (визуальная схема на 18 слотов и пресет `Колесо на Y`), `Проверка кнопок` (19 индикаторов), калибровка осей, `Мастер настройки` для Класса C и переключатель `Редактора интерфейса` (`F10`).
