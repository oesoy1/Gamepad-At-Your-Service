# Установка и удаление

[In English](../en/INSTALL.md) / [На главную](../../README.ru.md)

Скачайте нужный архив `.zip` в разделе [Releases](https://github.com/oesoy1/Gamepad-At-Your-Service/releases):
- `Gamepad-At-Your-Service-vX.Y.Z-GAMMA-Standard.zip` для обычной S.T.A.L.K.E.R. G.A.M.M.A. (`AnomalyDX11AVX.exe`, `AnomalyDX11.exe`, `SDL3.dll`). Основной вариант для большинства игроков.
- `Gamepad-At-Your-Service-vX.Y.Z-GAMMA-DLSS-Optional.zip` для G.A.M.M.A. с DX12-мостом, DLSS, генерацией кадров и FSR 3 (`AnomalyDX12-DLSS.exe`, `SDL3.dll`, библиотеки DLSS/FSR/Streamline/D3D12, меню и патч шейдеров DLSS). Архив полностью самодостаточный и не требует отдельного мода на DLSS (если он стоял раньше, отключите его). Для генерации кадров включите планирование GPU с аппаратным ускорением (HAGS) в настройках графики Windows и отключите MSAA с вертикальной синхронизацией в игре.

Перед установкой или обновлением файлов движка полностью закройте игру.

## Установка в G.A.M.M.A.

1. Перетащите скачанный `.zip` прямо в окно Mod Organizer 2 (или нажмите `Install a new mod from an archive`) и подтвердите имя мода `GAMMA Gamepad & Tactical UI`. Поставьте галочку напротив мода и перетащите его в самый низ левого списка прямо над `G.A.M.M.A. End of List_separator`. Моды `446- Quick Action Wheel - HarukaSai` и `G.A.M.M.A. Quick Action Wheel Balance` оставьте включёнными выше.
2. Нажмите правой кнопкой по моду `GAMMA Gamepad & Tactical UI` в MO2 и выберите `Open in Explorer` (Открыть в проводнике). Запустите `Установить_движок.cmd` (или `Install_Engine.cmd`) либо [скопируйте файлы движка вручную](#ручная-установка-без-cmd). Скрипт сам найдёт папку вашей Anomaly через `ModOrganizer.ini`, сохранит оригинальные файлы в `<Anomaly>\bin\_gamepad_backup\` и сверит контрольные суммы. Для версии с DLSS выберите в MO2 запуск файла `<Anomaly>\bin\AnomalyDX12-DLSS.exe`.
3. Выключите систему ввода Steam (`Свойства -> Контроллер -> Отключить систему ввода Steam`) и закройте DS4Windows, reWASD и x360ce при подключении по кабелю или через адаптер Xbox, чтобы нажатия не задваивались.

Проверить правильность путей, контрольные суммы и порядок модов перед запуском можно из папки мода (скрипт работает только на чтение):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "tools\verify.ps1"
```

В игре откройте `Настройки -> Управление -> Геймпад -> Другие настройки`, выберите значки `Dot Marks` и проверьте отклик осей и кнопок в окне `Проверка кнопок` (выход по удержанию `B` на 1 секунду). В мире памятка по кнопкам открывается сочетанием `LB + View`.

## Ручная установка без CMD

Установите и включите мод в MO2, как в первом пункте обычной инструкции. Для ручного способа достаточно Проводника и MO2.

1. Закройте игру. В MO2 откройте список исполняемых файлов (**Edit Executables**) и посмотрите поле **Binary** у обычного запуска G.A.M.M.A. Папка `bin`, в которой лежит этот `.exe`, нужна для установки. Запомните путь к исходному `.exe`, чтобы вернуть его при удалении мода.
2. Откройте папку установленного мода через **Open in Explorer**, затем зайдите в `engine_files`. До копирования сохраните отдельную копию папки `bin` с исходными файлами. По этой копии можно будет отличить заменённые файлы от добавленных.
3. Скопируйте файлы из `engine_files` в папку игры `<Anomaly>\bin\`:

   | Архив | Что копировать |
   |---|---|
   | **GAMMA Standard** | `AnomalyDX11AVX.exe`, `AnomalyDX11.exe` и `SDL3.dll`. |
   | **GAMMA DLSS Optional** | Всё содержимое `engine_files`, кроме `engine_helper.ps1`. Папки `D3D12` и `streamline` копируйте целиком. |

   Копируйте **содержимое** `engine_files` прямо в `bin`. Подтвердите замену совпадающих файлов после того, как сделали резервную копию. Для DLSS папки `D3D12` и `streamline` должны лежать рядом с `AnomalyDX12-DLSS.exe`.
4. Запустите игру через MO2. Для Standard используйте обычный пункт запуска G.A.M.M.A. Для DLSS укажите в поле **Binary** путь к `<Anomaly>\bin\AnomalyDX12-DLSS.exe`.

### Удаление после ручной установки

Закройте игру. Для каждого скопированного файла проверьте, был ли он в резервной копии `bin`. Если был, верните оригинал по тому же пути. Если появился при установке мода, удалите его. Если для DLSS меняли поле **Binary** в MO2, верните путь к исходному `.exe`. Затем снимите галочку с мода в MO2.

## После обновления через G.A.M.M.A. Launcher

Кнопка `Install / Update` в `G.A.M.M.A. Launcher` возвращает стандартный `.exe` в `<Anomaly>\bin\`. Настройки геймпада (`appdata\gamepad\profile.ltx`) и сохранения при этом не затрагиваются: откройте папку мода в проводнике и снова запустите `Установить_движок.cmd`. Скрипт обновит резервную копию новым стоковым файлом и вернёт движок с поддержкой геймпада. Повторный запуск `Установить_движок.cmd` никогда не затирает чистый бэкап файлами мода.

Если ставили вручную, сохраните копии свежих оригинальных файлов, которые вернул лаунчер, и снова скопируйте файлы движка из `engine_files` по [ручной инструкции](#ручная-установка-без-cmd). Сохраните и прежнюю резервную копию для файлов, которые лаунчер не заменил.

## Удаление мода

Если копировали файлы через Проводник, используйте [ручное удаление](#удаление-после-ручной-установки).

1. Откройте папку мода `GAMMA Gamepad & Tactical UI` из MO2 (`Open in Explorer`) и запустите `Вернуть_оригинал.cmd` (или `Restore_Original.cmd`). Он вернёт все оригинальные файлы из `<Anomaly>\bin\_gamepad_backup\`, удалит добавленные файлы мода и очистит папку `_gamepad_backup\`.
2. Снимите галочку с `GAMMA Gamepad & Tactical UI` в MO2 (или удалите мод).
3. При желании удалите папку `<Anomaly>\appdata\gamepad\` и лог `<Anomaly>\appdata\gamepad_last_error.log`.

В файлы сохранений `.scop` и `.scoc` мод ничего не пишет, сейвы загружаются без него как обычно.
